# 主题天 Theme-Day

> 今天，也给生活一个小目标。

**主题天**是一个轻量化的「主题生活挑战」工具。维护你的主题 → 随机抽取 → 持续几天 → 每天完成打卡。没有社交、没有商城、没有积分墙，只有你和你的小目标。

---

## 功能一览

- **抽主题** — 从启用主题中随机抽取，持续 3～7 天
- **每日打卡** — 完成当日目标后一键勾选，随机鼓励语
- **往日补卡** — 忘记打卡？可以补回来（人性化）
- **换一个** — 刚抽到不合适的？每轮可重新抽取几次
- **提前结束** — 确实不方便时可以提前结束本轮
- **主题管理** — 新建 / 编辑 / 删除 / 搜索 / 启用停用，完整 CRUD
- **不重复抽取** — 已完成过的主题会暂时休息，轮完一圈再重来
- **历史记录** — 查看每一轮挑战的完成情况与统计
- **PWA 支持** — 可添加到主屏幕，离线可用

## 技术栈

- **纯前端**：HTML + CSS + Vanilla JavaScript，零依赖，无构建步骤
- **数据存储**：LocalStorage（数据抽象层封装，方便后续切换数据库）
- **视觉风格**：米菲系低饱和配色 + 清新可爱装饰
- **响应式设计**：移动端优先，适配手机 / 平板 / 电脑
- **PWA**：manifest.webmanifest + Service Worker 离线缓存

## 快速开始

### 方式一：直接打开（最简单）

双击 `index.html` 即可在浏览器中使用。数据保存在浏览器 LocalStorage 中。

> ⚠️ 注意：`file://` 下 Service Worker 不生效，离线缓存和「添加到主屏幕」需要通过 HTTP 服务访问。

### 方式二：本地 HTTP 服务

```bash
# Python
python3 -m http.server 8000

# Node.js
npx serve .
```

然后打开 http://localhost:8000

### 方式三：部署到服务器

将所有文件放到任意 Web 服务器的根目录即可（Nginx / Apache / Caddy 等），无需额外配置。

## 项目结构

```
Theme-Day/
├── index.html              # 单页应用入口
├── manifest.webmanifest    # PWA 清单文件
├── sw.js                   # Service Worker（离线缓存）
├── assets/
│   └── miffy-swing.jpg     # Logo 图片
├── css/
│   └── style.css           # 米菲风样式表
└── js/
    ├── data.js             # 默认主题数据（14 个预置主题）
    ├── storage.js          # 数据存储抽象层（LocalStorage）
    └── app.js              # 主应用逻辑
```

## 浏览器支持

- Safari（支持添加到主屏幕）
- Firefox（基本功能正常）

## 设计理念

1. **简单好用** — 打开 → 看今天主题 → 完成目标 → 打勾
2. **手机优先** — 底部固定导航，单手可操作
3. **仪式感** — 随机鼓励语、进度可视化、米菲风视觉
4. **数据可靠** — 导出/导入备份，不怕丢数据
5. **可扩展** — 数据层抽象封装，后续可无缝接入后端
